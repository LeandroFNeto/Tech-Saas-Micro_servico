# Central de Ajuda e Manutenção de Comandos (AJUDA.md)

O arquivo `AJUDA.md` na raiz do projeto é a **Fonte Única de Consulta Rápida** de todos os comandos, skills e rotinas disponíveis para o time e para os agentes no projeto Tech-SaaS.

## Regras de Manutenção Ativa

1. **Atualização Imediata:** Sempre que uma nova skill, comando (`slash command`), script de automação ou fluxo de trabalho for adicionado, alterado ou removido no repositório, o arquivo `AJUDA.md` **deve ser atualizado no mesmo turno**.
2. **Conteúdo Obrigatório em AJUDA.md:**
   - Nome do comando ou atalho (ex: `/openspec`, `/horadoshow`, `/ponytail`, etc.).
   - Descrição sucinta do que ele faz.
   - Parâmetros aceitos e exemplos práticos de uso.
   - Restrições ou regras acopladas (como necessidade de aprovação ou arquivos de contexto).
3. **Respostas ao Usuário:** Quando o usuário perguntar "quais comandos existem?", "como uso tal skill?" ou solicitar ajuda sobre as operações do projeto, o agente deve consultar `AJUDA.md` para fornecer instruções alinhadas com as diretrizes vigentes.
